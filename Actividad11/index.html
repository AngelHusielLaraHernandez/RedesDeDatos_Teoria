Algoritmos Simétricos
y Algoritmos Asimétricos

Según AWS e IBM, la criptografía transforma datos legibles en un formato ininteligible mediante algoritmos matemáticos. Es el pilar fundamental de la privacidad digital moderna.

Algoritmos Simétricos

Criptografía de Clave Secreta.

Fundamento Técnico

Estos algoritmos operan bajo un principio sencillo: se utiliza la misma clave tanto para cifrar como para descifrar la información. Es como tener una caja fuerte donde la misma llave que la cierra es la única que puede abrirla.

Características Principales

  • Rendimiento superior: Ejecución muy rápida y bajo costo computacional, ideal para procesamiento masivo sin latencia.
  • Estándares: AES (Advanced Encryption Standard), ChaCha20, DES, 3DES.

Usos Comunes

  • Son el motor de trabajo principal para asegurar cargas útiles (payloads) en la red.
  • Cifrado del tráfico de información dentro de un túnel VPN.
  • Protección de datos en reposo, por ejemplo, cifrando todo el contenido de un disco duro.

Seguridad que trabajan

▸ Confidencialidad: Garantizan que la información sea ilegible para cualquier persona que intercepte el tráfico de red sin la clave secreta original.
▸ Fortalezas: Computacionalmente rápidos y eficientes. Ideales para cifrar volúmenes de datos sosteniendo velocidades sin latencia.
El Reto (Vulnerabilidad):

La distribución de claves. ¿Cómo le envías la clave secreta inicial al destinatario de forma segura? Si alguien la intercepta en el camino, la seguridad colapsa.

Algoritmos Asimétricos

Criptografía de Clave Pública.

Fundamento Técnico

Estos algoritmos utilizan un par de claves matemáticamente vinculadas: una Clave Pública (que puede compartirse con todo el mundo) y una Clave Privada (que el propietario debe guardar celosamente y nunca compartir).

Características Principales

  • Direccionalidad: Lo que se cifra con la pública, solo se puede descifrar con la privada, y viceversa.
  • Solución a la Distribución: Resuelven el problema de intercambiar claves en canales inseguros.
  • Estándares: RSA, ECC (Criptografía de Curva Elíptica), DSA.

Usos Comunes

  • Establecer canales seguros e intercambiar claves (por ejemplo, al iniciar una conexión SSH hacia un router).
  • Verificar identidades digitales mediante el uso de certificados digitales.
  • Base tecnológica fundamental de las criptomonedas y sus firmas (Blockchain).

Seguridad que trabajan

▸ Confidencialidad y No Repudio: Si alguien cifra con tu pública, solo tú descifras. Si tú firmas con tu privada, se garantiza indudablemente tu autoría.
▸ Fortalezas: Resuelven el problema de distribución. La clave pública puede viajar por canales inseguros sin riesgo.
El Reto (Vulnerabilidad):

Matemáticamente tan complejos que resultan miles de veces más lentos. No son viables para flujos de datos en tiempo real.

El Sistema Híbrido: Lo Mejor de Ambos Mundos

Trabajando en equipo en la red real.

En los protocolos de seguridad de red reales (como HTTPS/TLS o IPsec), rara vez se usa uno solo. Se combinan para aprovechar los puntos fuertes de cada uno:

Fase Asimétrica

Se utiliza criptografía asimétrica (como Diffie-Hellman o RSA) para autenticar a las partes y negociar de forma completamente segura una clave secreta a través de la red abierta de internet.

Fase Simétrica

Una vez que ambos extremos tienen la misma clave secreta compartida, descartan el canal asimétrico y usan criptografía simétrica (como AES) para cifrar el resto de la comunicación a muy alta velocidad.
